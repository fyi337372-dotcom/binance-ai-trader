# 飞书权限开通说明

## 需要开通的权限

### 1. 当前问题
飞书 API 返回错误：im:contact:contact.base:readonly 权限不足

### 2. 需要开通的权限列表

| 权限名称 | 用途 |
|---------|------|
| im:contact:contact.base:readonly | 读取联系人信息 |
| im:message:send_as_bot | 发送消息 |
| im:message:readonly | 读取消息 |
| im:chat:read | 读取会话列表 |

### 3. 开通步骤

1. 打开飞书开放平台：https://open.feishu.cn/app/cli_a9295bd300b85bde/auth
2. 使用管理员账号登录
3. 在"权限管理"中找到上述权限
4. 点击"开通"按钮
5. 选择"全员开通"或指定应用范围

### 4. 授权链接

直接访问以下链接开通：
https://open.feishu.cn/app/cli_a9295bd300b85bde/auth?q=contact:contact.base:readonly
